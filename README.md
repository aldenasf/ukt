# Uji Kenaikan Tingkat (UKT) - SMKN 1 Jenangan XI RPL

Repository ini dibuat untuk memenuhi tugas **Uji Kenaikan Tingkat (UKT)** SMK jurusan **Rekayasa Perangkat Lunak (RPL)** kelas XI.

Detail soal, database, serta panduan pengerjaan ujian dapat dilihat pada folder [`docs/`](./docs/):

- `docs/Soal UKT.pdf` : Lembar soal dan instruksi pengerjaan ujian praktik.
- `docs/db_peminjama_alat.sql` : Skema database dan seeding.
- `docs/01 Instalasi.pdf` & `docs/Instalasi Tailwind.pdf` : Panduan setup dan instalasi environment.
